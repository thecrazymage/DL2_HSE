# Deep Learning 2 HSE

This repo contains lectures slides, seminars notebooks and homeworks for the "Deep Learning 2" course at the [Faculty of Computer Science](https://cs.hse.ru/en/) of [HSE University](https://www.hse.ru/en/). 

Details about the course organization can be found at
the [wiki page](https://wiki.cs.hse.ru/%D0%93%D0%BB%D1%83%D0%B1%D0%B8%D0%BD%D0%BD%D0%BE%D0%B5_%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5_2_2026) (in Russian).

## General information

1. The course provides **4 homework assignments** and **2 practice tasks**.
2. Evaluation formula (arithmetic rounding):
    - MOP and AI360:
    $$S = \text{round}\left(0.4\cdot\text{Practice} + 0.4\cdot\text{HW} + 0.2\cdot\text{Final Test}\right)$$
    - KNAD: 
    $$S = \text{round}\left(0.7\cdot\text{HW} + 0.3\cdot\text{Final Test}\right)$$
3. Course components:
    - Homeworks: 4 homework assignments in total.
    - Practice (for AI360 & MOP):
        - Participation in a competition.
        - Task transferred from another course.
    - Final Test: questions covering one lecture block.
